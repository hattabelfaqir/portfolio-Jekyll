## 📌 Présentation du projet

Ce projet est un **portfolio personnel** réalisé dans le cadre d’un **projet scolaire chez Hippitech**.  
L’objectif principal était de concevoir un **CV sous forme de site web**, en utilisant **Jekyll** et **GitHub Pages**, afin de comprendre le fonctionnement d’un site statique, sa structure et son déploiement.

Le site est désormais **terminé dans sa version actuelle**.

---

## 🎯 Objectifs pédagogiques

- Découvrir et comprendre le fonctionnement de **Jekyll**
- Mettre en place un site statique structuré
- Organiser le contenu (pages, projets, navigation)
- Déployer un site sur **GitHub Pages**
- Comprendre les limites et avantages d’une technologie peu utilisée aujourd’hui

Même si Jekyll est une technologie **peu répandue et peu moderne**, cette expérience a été très enrichissante et m’a permis d’apprendre de nouvelles notions importantes.

## 🚀 Évolution du projet

Ce portfolio est voué à évoluer :

- Le site sera **mis à jour régulièrement**, environ tous les **2 mois**
- Le thème actuel sera remplacé à terme par un **thème 100 % personnalisé**
- Jekyll ne sera probablement plus utilisé dans la version finale
- Le projet deviendra un **portfolio full stack**, entièrement développé avec mes propres choix techniques et stylistiques

Ce site restera cependant une **vitrine centrale**, regroupant l’ensemble de mes projets et compétences, avec une version toujours plus propre et aboutie.

---

## ℹ️ Remarques

Le temps de développement étant limité à **une semaine**, l’accent n’a pas été mis sur le design, mais plutôt sur :
- la **structure**
- la **compréhension du fonctionnement du site**
- la **clarté du contenu**
